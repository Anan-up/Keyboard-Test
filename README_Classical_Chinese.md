以一 HTML 文件，成**全尺寸百八鍵鍵盤測試之器**，可實時察諸鍵之觸發，復計 APM（每分操作之數），圖其變化。

---

## 一、功能概說

- **鍵盤佈局之繪**
  構標準全尺寸之鍵盤（主鍵之域、導航之區、小鍵之盤），凡百有八物理之鍵（功能、編輯、方向、小鍵之屬咸備）。諸鍵以 CSS Grid 與 Flex 之法動態生焉，其大小隨境而變（`clamp` 之響應單位）。

- **實時監鍵**
  監 `keydown` / `keyup` 之事，依 `event.code` 及 `event.location` 精確繫於相應之 DOM，同步其形：
  - 按下之時 → **黑底白字**（`active` 之類）
  - 釋而後 → **灰底**（`hit` 之類），示此鍵曾觸
  - 未觸者 → **白底**

- **統計之目**
  頂欄列五數：
  - **瞬時 APM**：近一秒內觸鍵之數，折算為每分之率
  - **峰值 APM**：曩時最高之瞬值
  - **總觸次**：累計觸鍵之數（復觸者亦計）
  - **已測之鍵**：曾觸之異鍵數／可繫之總鍵數
  - **最近之鍵**：示末觸之鍵名、原 `code` 及 `location`（便於診）

- **鎖狀之示**
  自察 `CapsLock`、`NumLock`、`ScrollLock` 之態，以 LED 圓點及諸鍵右上之小圓點同示之。

- **APM 之曲**
  以 Canvas 繪之，每五百毫秒采瞬時 APM 一次，存近百二十點（即六十秒之窗），其線滾動而新，且示今之瞬值。

- **重置之能**
  一鍵清空諸統計、曲線之數及高亮之態，復其初。

## 二、技術之實

### 1. 頁面之構與佈
- 兼用 Flex 與 CSS Grid 之佈。頂 `topbar` 含曲圖與統計之卡；中鍵盤之體分為 `main`（主鍵之列）、`nav`（導航之列）、`numpad-col`（小鍵之列）。
- 諸鍵之大小由 CSS 之變 `--u` 控之（`clamp(24px, 4.3vw, 50px)`），隨屏而適。
- 跨行跨列之鍵（如小鍵之 `+`、`Enter`、`0`），以 `grid-row: span 2` 或 `grid-column: span 2` 成之。

### 2. 以數驅生
- 諸鍵咸定於 JavaScript 之陣中。每鍵之體含 `label`（所顯之文）、`code`（應 `event.code`）、`w`（寬之倍，許一·二五、一·五、二·二五之屬）及 `cls`（外加之類，如 `tall` ／ `wide`）。
- 導航之區含 `spacer` 之虛位，以正行列之齊。
- 繪之時遍歷其數以生 DOM，立 `code -> DOM` 之繫表（`codeMap`），便於事回之速索。

### 3. 事之處與鍵之辨
- **修鍵左右之辨**
  於 `Shift`、`Control`、`Alt`、`Meta`，先以 `event.location`（`LEFT=1` ／ `RIGHT=2`）判左右，弗專恃 `event.code`（或系或輸入法或誤報）。若 `location` 為 `0`（莫能辨）而 `code` 空，則斷為異常之注事（如右 Shift 見劫），依右鍵處之。
- **止其默行**
  於空格、方向、Tab、Backspace、功能諸鍵，調 `preventDefault()`，以防頁滾或易焦，保測不受擾。
- **失焦之處**
  頁失其焦（如按 Win 鍵而啟菜），則清諸鍵之 `active` 態，免「鍵滯」之妄。

### 4. APM 之算與繪
- **瞬時 APM**：維一時戳之陣 `hits`，記每觸之 `performance.now()` 時戳。算時取近一秒之數，乘六十為每分之率。
- **峰值 APM**：較每更後之瞬值，存其極。
- **曲線之圖**：
  - 每五百毫秒采瞬時 APM 一次，納於環緩 `apmBuf`（至多百二十點）。
  - 繪時，Y 軸以六十之整倍為刻之上限（動取整），X 軸自右向左滾（新點恆於最右）。
  - 含網線、填域、折線，彰其今值。

### 5. 鎖狀之同
- 於 `keydown` 與 `keyup` 中調 `e.getModifierState()`，得三鎖之態，更 LED 之示與鍵上之小點。

## 三、交互之詳

| 操 | 視之反 | 統之更 |
|----|--------|--------|
| 按任一鍵 | 其鍵為黑底白字（`active`），且立標「已觸」（加 `hit` 類，釋後留灰底） | 記時戳，總數加一，更瞬 APM、峰值、近鍵、已測之鍵 |
| 釋鍵 | 去黑底，留灰底 | 無新統（然鎖狀或變） |
| 切鎖鍵 | LED 與鍵點同明滅 | 無 |
| 頁失焦 | 盡去黑底 | 無 |
| 重置之鍵 | 諸鍵盡去黑白灰底 | 清空諸統、曲緩，APM 歸零 |

**要設**：
- 於 `keydown` 中並加 `hit` 類，縱 `keyup` 之失（如 Win 鍵啟始菜），亦存「已觸」之標。
- 近鍵之示附 `code` 與 `location`，便調鍵繫之當否。

## 四、設計之善

1. **準且兼容**
   - 兼容諸系諸瀏之鍵異（如 Mac 之 Meta 鍵）。
   - 修鍵左右，以 location 與 code 雙驗，應輸入法見劫之況。

2. **視反昭然**
   - 三態之色（白黑灰）晰分「未觸／按下／已觸」。
   - 鎖鍵之點與系態同，無滯。

3. **效能之優**
   - 以 `performance.now()` 代 `Date.now()`，益其精。
   - 定時之隙（二百五十毫秒更統，五百毫秒采曲），調暢與能。

4. **應境之設**
   - 鍵之大小隨視口而變，手機、平板、桌機咸宜。
   - Canvas 依 devicePixelRatio 調其析，保高清之晰。

5. **導用之便**
   - 底有說明，釋色之義與用，降用之門。
