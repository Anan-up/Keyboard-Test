使用一个 HTML 文件实现了一个**全尺寸 108 键键盘测试工具**，用于实时监测按键触发情况，并提供 APM（Actions Per Minute，每分钟操作次数）统计与可视化。

---

## 一、功能概述

- **键盘配列渲染**  
  构建了标准全尺寸键盘（主键区、导航键区、小键盘区），包含 108 个物理键位（含功能键、编辑键、方向键及小键盘）。每个按键以 CSS Grid 和 Flex 布局动态生成，尺寸自适应（`clamp` 响应式单位）。

- **实时按键监测**  
  监听 `keydown` / `keyup` 事件，根据 `event.code` 及 `event.location` 准确映射到对应 DOM 元素，并同步视觉反馈：
  - 按下时 → **黑底白字**（`active` 类）
  - 松开后 → **灰底**（`hit` 类），表示该键已被触发过
  - 未触发 → **白底**

- **统计指标**  
  顶栏显示五项数据：
  - **瞬时 APM**：最近 1 秒内的按键次数折算成每分钟速率
  - **峰值 APM**：历史最高瞬时值
  - **总触发次数**：累计按键次数（含重复触发）
  - **已测键位**：已触发过的不同键位数量 / 总可映射键位数
  - **最近按键**：显示最后触发的键名、原始 `code` 及 `location` 值（便于诊断）

- **锁定状态指示**  
  自动读取 `CapsLock`、`NumLock`、`ScrollLock` 状态，通过指示灯（LED 圆点）及对应按键右上角小圆点同步显示。

- **APM 曲线图**  
  基于 Canvas 绘制，每 500ms 采样一次瞬时 APM，保存最近 120 个点（即 60 秒窗口），曲线滚动更新，并显示当前瞬时值。

- **重置功能**  
  一键清空所有统计、曲线数据及按键高亮状态，恢复初始状态。

## 二、技术实现

### 1. 页面结构与布局
- 使用 Flex 和 CSS Grid 混合布局，顶部 `topbar` 包含曲线图和统计卡片，中部键盘主体分为 `main`（主键列）、`nav`（导航列）、`numpad-col`（小键盘列）。
- 键盘按键尺寸由 CSS 变量 `--u` 控制（`clamp(24px, 4.3vw, 50px)`），适应不同屏幕尺寸。
- 跨行/跨列按键（如小键盘 `+` 和 `Enter`、`0`）通过 `grid-row: span 2` 或 `grid-column: span 2` 实现。

### 2. 数据驱动生成
- 所有键位定义在 JavaScript 数组中，每个键位对象包含 `label`（显示文本）、`code`（对应 `event.code`）、`w`（宽度倍数，支持 1.25、1.5、2.25 等）及 `cls`（额外类，如 `tall` / `wide`）。
- 导航区包含 `spacer` 占位元素，用于保持行列对齐。
- 渲染时遍历数据生成 DOM，并建立 `code -> DOM 元素` 的映射表（`codeMap`），方便事件回调快速查找。

### 3. 事件处理与键位识别
- **修饰键左右区分**  
  针对 `Shift`、`Control`、`Alt`、`Meta`，优先使用 `event.location`（`LEFT=1` / `RIGHT=2`）判断左右，避免单纯依赖 `event.code`（某些系统或输入法可能误报）。当 `location` 为 `0`（即无法判断）且 `code` 为空时，判断为异常注入事件（如右 Shift 被劫持），按右侧键处理。
- **阻止默认行为**  
  对空格、方向键、Tab、Backspace、功能键等调用 `preventDefault()`，防止页面滚动或切换焦点，保证测试不受干扰。
- **失焦处理**  
  当页面失去焦点（如按下 Win 键弹菜单）时，清空所有按键的 `active` 状态，避免“卡键”假象。

### 4. APM 计算与绘图
- **瞬时 APM**：维护一个时间戳数组 `hits`，记录每次按键的 `performance.now()` 时间戳。计算时截取最近 1 秒内的次数，乘以 60 换算为每分钟速率。
- **峰值 APM**：比较每次更新后的瞬时值，保留最大值。
- **曲线图**：
  - 每 500ms 采样一次瞬时 APM，存入环形缓冲区 `apmBuf`（最多 120 点）。
  - 绘制时，Y 轴以 60 的整数倍为刻度上限（动态取整），X 轴从右向左滚动（最新点固定在最右侧）。
  - 包含网格线、填充区域和折线，突出当前值。

### 5. 锁定状态同步
- 在 `keydown` 和 `keyup` 中调用 `e.getModifierState()` 获取三个锁定键状态，更新 LED 指示灯和键位上的小圆点。

## 三、交互逻辑细节

| 操作 | 视觉反馈 | 统计更新 |
|------|----------|----------|
| 按下任意键 | 对应键位变为黑底白字（`active`），且立即标记为“已触发”（加 `hit` 类，松开后保留灰底） | 记录时间戳，总次数 +1，更新瞬时 APM、峰值、最近按键、已测键位 |
| 松开按键 | 黑底移除，灰底保留 | 无新增统计（但锁定状态可能变化） |
| 切换锁定键 | LED 及键位圆点同步亮/灭 | 无 |
| 页面失焦 | 所有黑底清除 | 无 |
| 重置按钮 | 所有按键清除黑底和灰底 | 清空所有统计数据、曲线缓存，APM 归零 |

**关键设计**：
- 在 `keydown` 中同时添加 `hit` 类，确保即使 `keyup` 事件丢失（如 Win 键弹出开始菜单）也能保留“已触发”标记。
- 最近按键显示附加 `code` 和 `location`，方便调试键位映射是否正确。

## 四、设计亮点与贴心之处

1. **准确性与兼容性**  
   - 兼容不同操作系统和浏览器下的键位差异（如 Mac 的 Meta 键）。  
   - 对修饰键左右位置做了双重校验（location + code），适应输入法劫持场景。

2. **视觉反馈直观**  
   - 三态颜色（白/黑/灰）清晰区分“未触发/按下/已触发”。  
   - 锁定键小圆点与系统状态同步，无延迟。

3. **性能优化**  
   - 使用 `performance.now()` 代替 `Date.now()` 提高精度。  
   - 定时器间隔（250ms 更新统计，500ms 采样曲线）平衡流畅度与性能。

4. **响应式设计**  
   - 按键尺寸随视口变化，在手机、平板、桌面均能良好显示。  
   - Canvas 依据 devicePixelRatio 调整分辨率，确保高清屏清晰。

5. **用户指引**  
   - 底部提示说明了颜色含义和功能，降低使用门槛。
